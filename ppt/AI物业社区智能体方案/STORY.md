# STORY.md — AI 物业社区智能体 · 方案汇报（深度版）

## ① 用户意图对齐

- **目标受众**：学校项目评审（老师 / 评委），技术评审 + 创新性评审 + 工作量评审
- **核心目标**：让评委看到「完整的从零构建过程」——数据库 → 后端 → 前端 → Agent → RAG → 评估 → 部署的完整技术路线，真实的虚拟社区规模，以及用数据证明的质量。记住三点：**规模真实、路线完整、质量有据**
- **PPT 长度**：17 页（封面 + 目录 + 4 章 + 结束）
- **视觉调性**：深蓝沉稳 / 香槟金点睛 / 数据密集 / 技术纵深
- **内容边界**：
  - 必讲：虚拟社区规模、完整技术路线（Phase 0-7）、数据库设计、AI 架构、RAG、功能闭环、量化评估、截图占位、demo
  - 不讲：费用在线支付（未实现）、IoT/视频巡检（硬件依赖）
  - 禁碰：夸大数据、编造未实现功能
