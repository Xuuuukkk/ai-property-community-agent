# AI Property Community Agent

# 项目愿景与范围（Vision and Scope）


## 1. 项目愿景（Project Vision）


本项目希望构建一个面向真实物业社区场景的 AI Native 智能体平台。


核心愿景：

> 让 AI 成为物业社区服务的新型入口，通过智能理解、业务执行和知识增强，实现人与社区服务之间的高效连接。


未来的物业系统不再只是：

```
用户

↓

功能菜单

↓

人工操作

↓

服务结果
```


而是：

```
用户

↓

AI Community Assistant

↓

理解用户需求

↓

调用业务能力

↓

完成任务

↓

反馈结果
```


---

# 2. 项目使命（Mission）


## 2.1 提升业主服务体验


通过 AI 助手，让业主可以：

- 自然语言咨询物业问题
- 快速提交维修需求
- 查询费用信息
- 获取社区规则解释
- 查看服务进度


降低：

- 沟通成本
- 等待时间
- 操作复杂度


---

## 2.2 提升物业运营效率


帮助物业人员：

- 自动处理重复咨询
- 快速生成公告
- 智能分配工单
- 查询社区数据


减少：

- 人工重复工作
- 信息传递错误
- 管理成本


---

## 2.3 探索 AI Agent 在真实业务中的应用


本项目不仅实现业务功能，同时验证：

- Agent架构设计
- 多智能体协作
- 工具调用能力
- RAG知识增强
- AI效果评估


---

# 3. 项目范围（Project Scope）


## 3.1 MVP阶段范围


MVP目标：

> 构建一个可运行、可验证的 AI 物业社区管理闭环。


包含三个用户角色：


```
拥有者

业主端


Admin

物业管理端


Worker

维修人员端
```


---

# 4. MVP功能范围（MVP Features）


## 4.1 业主端（Owner）


### AI社区助手

支持：

- 物业咨询
- 报修入口
- 费用查询
- 公告查询


---

### 智能报修


用户：

```
我家卫生间漏水
```


AI：

1. 判断维修意图
2. 收集必要信息
3. 创建维修工单
4. 返回处理结果


---

### 工单查询


业主可以查看：

- 工单编号
- 当前状态
- 维修人员
- 完成时间


---

### 物业费用查询


支持：

- 当前费用
- 缴费状态
- 历史记录


---

## 4.2 物业管理端（Admin）


包含：

### 工单管理

能力：

- 查看工单
- 分配维修人员
- 修改状态
- 查看处理记录


---

### 用户和房屋管理

管理：

- 业主信息
- 楼栋信息
- 房屋信息


---

### 公告管理


支持：

- 创建公告
- AI辅助生成
- 发布通知


---

## 4.3 维修人员端（Worker）


支持：

- 查看维修任务
- 接收工单
- 更新状态
- 上传维修结果


---

# 5. AI能力范围（AI Scope）


## 5.1 Router Agent


负责：

理解用户意图，并选择对应业务 Agent。


例如：

输入：

```
我要查物业费
```


输出：

```
Fee Agent
```


---

## 5.2 Repair Agent


负责：

- 识别维修需求
- 收集信息
- 创建工单
- 查询状态


---

## 5.3 Fee Agent


负责：

- 查询费用数据
- 返回账单信息
- 解释费用情况


---

## 5.4 Notice Agent


负责：

- 公告内容生成
- 格式优化
- 文案辅助


---

## 5.5 Knowledge Agent


负责：

基于 RAG 知识库回答：

- 物业规则
- 装修规范
- 社区制度
- 服务流程


---
