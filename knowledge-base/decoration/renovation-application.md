# 云溪花园装修申请、审批、验收及押金退还全流程

> RAG知识库：答复装修要交什么材料、怎么走流程、完工如何退保证金等问题

## 一、装修申请提交材料清单

业主前往物业服务中心办理装修备案，一次性提交以下资料：

1. 房屋不动产权证书/购房合同复印件；
2. 装修平面布局图纸，重点标注墙体拆改、水电走向、厨卫防水改造区域；
3. 施工负责人及所有装修工人身份证正反面复印件；
4. 填写《云溪花园房屋装修申请表》《装修安全承诺书》，签字确认。

## 二、物业内部审批流程

1. 工程岗审核图纸：核查是否存在承重墙拆除、剪力墙开孔、外立面改动、燃气管道移位等违规设计；
2. 审核通过后缴纳装修履约保证金，开具缴费凭证；
3. 为施工人员办理临时小区出入证，告知垃圾堆放点、货梯使用规则、施工时间禁令。

## 三、施工过程中期巡检

1. 物业工程人员不定期上门巡查，核对现场施工是否与报备图纸一致；
2. 重点核查：承重结构完好性、防水层闭水试验、燃气管线保护、外立面有无私自打孔。
3. 发现违规立即下发停工整改通知书，整改合格后方可恢复施工。

## 四、装修完工竣工验收与押金退还

1. 业主全屋装修完毕后，主动向物业服务中心提交竣工验收申请；
2. 物业上门现场核验：墙体结构、外墙外立面、公共区域恢复、垃圾清理情况；
3. 核验无任何违规损坏后，启动保证金退款流程，**30个工作日内全额无息原路返还**；
4. 若产生结构破坏、外墙损伤、公共设施污损，从保证金中抵扣修复费用，不足部分向业主追偿。
