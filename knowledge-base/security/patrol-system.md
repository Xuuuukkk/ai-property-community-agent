# 云溪花园安保巡逻工作规范

> RAG知识库：巡逻频次、巡查点位、异常处置、监控运维规则

## 一、巡逻频次与路线

1. 白班：每2小时对园区路面、绿化带、围墙、非机动车棚、设备房巡回巡查一次。
2. 夜班：加密至每1小时巡逻一次，重点检查地下车库、消防通道、配电房、水泵房、围墙死角。
3. 安保人员使用电子巡更系统打卡留痕，所有记录后台存档备查。

## 二、重点巡查内容

1. 检查消防通道是否被车辆、杂物堵塞，消火栓、灭火器是否完好有效。
2. 排查车库漏水、管线异响、门窗破损、可疑人员逗留、电动车违规入户充电等风险。
3. 夜间查看园区照明、围墙护栏、监控摄像头是否正常工作。

## 三、突发事件处置流程

1. 发现火情、漏水、高空坠物、斗殴、盗窃等险情，第一时间上报物业中控室。
2. 现场做好临时警戒，疏散周边人员，同步拨打110、119、120等应急电话。
3. 事后填写巡查异常台账，闭环跟进整改。
