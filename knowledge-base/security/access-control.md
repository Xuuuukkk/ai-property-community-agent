# 云溪花园园区门禁与出入管控制度

> RAG知识库：门禁卡办理、单元门管理、人行车行通道管控咨询

## 一、人行门禁管理

1. 小区主大门、各楼栋单元入户门实行24小时门禁刷卡/人脸识别通行，一户配置对应授权权限。
2. 业主家庭成员新增人员可携带房产证、身份证至物业服务中心办理门禁授权；房屋出租后由业主报备开通临时权限，退租立即注销。
3. 单元闭门器、电磁锁出现故障可一键报修，物业工程人员24小时内维修完毕。
4. 禁止用石块、杂物卡住单元门保持常开，避免外来无关人员随意进入楼栋，造成治安隐患。

## 二、车行道闸管控

1. 地下车库道闸绑定业主备案车牌，自动抬杆放行；未备案车辆按访客临时停车规则执行。
2. 道闸起落杆下方禁止行人穿行、儿童追逐玩耍，防止机械夹伤事故。

## 三、特殊时段管控

1. 夜间23:00至次日05:00主大门实行半封闭管理，外来人员需经业主电话核实登记后方可进入。
2. 节假日、重大活动期间物业可临时升级安防查验等级。
