# 云溪花园业主投诉受理、处置与闭环回访制度

> RAG知识库：投诉渠道、答复时限、处理流程、结果反馈规则

## 一、四大投诉提交渠道

1. 线上智能AI客服助手提交文字+图片描述；
2. 物业服务中心前台现场填写《业主投诉登记表》；
3. 物业24小时服务热线电话反馈；
4. 向小区业主委员会书面递交投诉意见书。

## 二、分级处置响应时限（上海物业规范硬性要求）

1. 紧急类投诉（漏水浸泡、电梯故障、大面积断电、消防隐患）：30分钟内到场核查处置；
2. 一般服务类投诉（保洁不到位、绿化损坏、邻里噪音、停车纠纷）：2个工作日内给出初步处置方案；
3. 复杂协调类投诉（邻里矛盾、公共收益质疑、规约执行争议）：5个工作日内组织多方沟通并书面回复。

## 三、完整闭环处理流程

1. 投诉登记建档 → 物业对应主管牵头核查现场情况；
2. 制定整改方案并告知投诉业主；
3. 落实整改、协调矛盾、修复问题；
4. 完成后电话回访投诉人，确认满意度；
5. 所有投诉工单统一归档留存，接受业委会与房管部门抽查查阅。

## 四、升级申诉路径

若对物业处置结果不认可，可依次向上申诉：

1. 小区业主委员会介入复核调解；
2. 属地街道办事处、社区居委会物业调解办公室；
3. 浦东新区住房保障和房屋管理局物业监管科室。
