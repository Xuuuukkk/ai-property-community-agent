# 云溪花园住宅物业服务等级执行标准

> RAG知识库：保洁、安保、绿化、设施维保、电梯年检等服务内容答疑

参照 DB31/T 360-2020《住宅物业管理服务规范》上海地方标准制定。

## 一、公共区域保洁服务标准

1. 楼栋大堂、电梯轿厢、楼道扶手、消防栓每日擦拭清洁，电梯地面每日吸尘拖地；
2. 地下车库地坪每周冲洗清扫，排水沟、集水井定期清淤，无积水、无油污淤积；
3. 园区道路、垃圾厢房每日定点清运，垃圾桶内外冲洗消杀，杜绝异味、蚊虫滋生；
4. 绿化带内白色垃圾、落叶枯枝每日巡回捡拾。

## 二、秩序维护与安保服务标准

1. 门岗实行24小时双人轮岗值守，外来人员、访客、装修工人核验登记；
2. 安保人员分时段对园区楼栋、地下车库、设备机房、围墙点位定时巡逻并留存巡更记录；
3. 监控机房7×24小时专人值守，画面异常、消防报警第一时间现场核实处置。

## 三、绿化养护管理标准

1. 园区乔木、灌木、草坪按季节修剪、除草、施肥、病虫害消杀；
2. 喷淋灌溉系统定期检修，高温干旱时段增加浇水频次；
3. 枯死绿植及时拔除补种，绿化带禁止业主私自开垦种菜、堆放杂物。

## 四、共用设施设备维保标准

1. 电梯每月维保、每年强制年检，张贴有效合格标志，轿厢内应急通话装置24小时畅通；
2. 二次供水水箱按规定频次清洗消毒，水质送检公示；
3. 消防水泵、喷淋、烟感、防火卷帘、应急照明每月联动测试，确保火灾状态正常启动；
4. 公共照明、给排水管网、排污泵月度巡检，故障24小时内修复。
